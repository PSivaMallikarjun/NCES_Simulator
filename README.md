# Optimizer: Non-Conventional Energy Efficiency Enhancer

**Optimizer** is a simple web app with jsp that calculates and visualizes energy output from non-conventional sources, starting with solar energy.

## 🚀 Features

- Energy output calculator (Solar panel size, sunlight hours, efficiency)
- Real-time efficiency suggestions
- Doughnut chart visualization using Chart.js
- Responsive and clean UI

## 🛠 Tech Stack

- HTML
- CSS
- JavaScript
- Chart.js (for visualization)

## 📦 Installation

1. Clone this repo:
https://github.com/PSivaMallikarjun/NCES_Simulator

2. Open `index.html` in any browser.
- Save results locally or export to CSV
